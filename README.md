# 🏡 Dream House – Real Estate Landing Page

Welcome to **Dream House**, a modern and responsive real estate landing page website designed to showcase beautiful properties and help users find their dream homes.

## 🌟 Features

- Modern and attractive landing page design
- Responsive layout for mobile, tablet, and desktop
- Property details and amenities
- Location highlights and property gallery
- Contact form for customer inquiries
- Google Reviews / customer testimonials section
- Smooth animations and interactive elements
- DTCP approval information section
- Easy navigation and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
